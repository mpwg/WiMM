# P4.1.8 — Übergabe

- Ergebnis: Der native lokale Wiedereinstieg ist auf macOS arm64 abgenommen. Ein synthetischer Tresor und Haushalt überstehen Sperren und einen neuen Start der gebündelten Tauri-Laufzeit; Passphrase und Rettungscode öffnen jeweils wieder den Haushalt.
- Geänderte Verträge: Keine.
- Geprüft: `pnpm --filter @wimm/desktop build` erstellt das Release-Binary ohne Warnungen. Anschließend wurde die gebündelte Tauri-Anwendung auf macOS 27.0.1 arm64 ohne Serverkonfiguration über ihre native Oberfläche bedient: Tresor anlegen, Rettungscode bestätigen, Passphrase-Entsperrung, Haushalt anlegen, sperren, neuer Prozess, Wiedereinstieg per Passphrase; erneut sperren, neuer Prozess, Wiedereinstieg per Rettungscode. Vor jedem Entsperren zeigte die native App ausschließlich den Sperrbildschirm. Der Test verwendete nur synthetische Daten; sein lokaler Profildatensatz wurde danach entfernt.
- Nicht geprüft: Windows, Linux und macOS x64; diese Plattformzellen bleiben für die spätere Plattformmatrix offen. Menüs und Dialoge sind kein Bestandteil von P4.1.8 und folgen in P4.5.
- Commits: Abschlusscommit dieser Dokumentation.
- Einschränkungen: Die Prüfung belegt keine native Dateidialog-, Menü- oder Shortcutbedienung und ersetzt keine P4.5-/P4.6-Abnahmen.
